An original web novel by **czverse**. Read it free at **https://czverse.github.io/asilaw/**

*Global Awakening: Unique Class Calamity Necromancer, My Supreme Intelligence Law Comprehends the Heavens 1000x Faster*

## How this repo works

- `chapters/chNN.md` holds one chapter each, starting with `## Chapter N: Title`.
- `python3 build_site.py chapters docs` rebuilds the whole site into `docs/`, which GitHub Pages serves.
- To publish new chapters: add the `.md` files, run the build, commit, push.
