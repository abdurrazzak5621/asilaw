These files record only what the published chapters establish. They were built from a full read of ch1–120 (October 2026).

**Rule:** the manuscript outranks these files, and these files outrank the old `bible.md`. If a new chapter changes anything here, update the file in the same commit as the chapter.

| `artifacts.md` | Staff, Law Cores, seeds, the Ledger and board, other objects |

| `cosmology.md` | Tiers, fields, keepers, Hungers, the Shallows naming question |
